# Keeping CHUD Alive!
### About
CHUD, short for "Computer Hardware Understanding Development Tools," was a development toolset made by Apple for troubleshooting and optimizing PowerPC-based Macs. Version 3.5.2 in particular enabled a CPU throttling feature known as "napping." This mode is especially useful on Power Mac G4 "Mirrored Drive Door" (MDD) models, as it considerably lowers idle CPU temperatures and, in turn, fan noise.

Nap Enabler is a helper utility that automatically re-enables "Nap" mode after each reboot. It requires CHUD 3.5.2 to be installed in order to function.

I created this repository to make this toolset available to anyone who still uses these excellent classic Apple computers. Enjoy!
